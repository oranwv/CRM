# Glossary

Project-specific terms, Hebrew vocabulary, and names.

- **Sharabiya / שרביה** — the event venue this CRM serves (Tel Aviv). Brand
  also surfaces as "proevent" (domain proevent.co.il).
- **ליד (lead)** — a prospective customer / event inquiry. Core entity.
- **תפעול (tipul/operations)** — the production/operations module: on-the-day
  tasks, inventory, maintenance, faults. See [[operations-and-docs]].
- **ניהול (nihul/management)** — admin/manager dashboard of employee activity.
- **פעילות (activity)** — a logged interaction (call, meeting, note) on a lead.
- **Green API** — third-party WhatsApp gateway (primary WhatsApp channel).
- **GreenInvoice** — Israeli invoicing service used to issue financial docs.
- **ח.פ / ת.ז / עוסק** — Israeli company/person tax IDs shown on financial docs.
- **Telekol / Call Event (hafakot)** — external lead-source channels parsed from email.
- **stage** — pipeline stage of a lead (new → … → won / lost).
- **mode** — the app's top-level view context (sales / operations / management),
  switched via `AppModeContext`.
